# Compound Writing Help

Compound Writing loads the context that already governs the work, then routes to the smallest useful writing workflow.

Use `scribe` when you want help starting, continuing, finishing, or improving a piece without choosing a skill first. The full toolbox is installed; `scribe` keeps the user from having to learn it all before beginning.

Use `setup-project` when you want a new self-contained writing folder. It creates `VOICE.md`, `STYLE.md`, `examples/`, and `drafts/`; use `onboarding` afterward to fill the guides.

## Common Routes

| You have | Start with |
|---|---|
| A new writing project to set up | `setup-project` |
| No idea | `brainstorm` |
| A live idea | `interview` |
| Notes or source material | `outline` |
| An outline or partial draft | `draft` |
| A structurally weak draft | `dev-edit` |
| Stable structure and rough prose | `line-edit` |
| Generic or machine-smoothed copy | `voice-check`, `ai-check`, or `tracks` |
| A fresh-eyes or first-time-reader check | `reader` |
| A nearly publishable piece | `final-pass` |
| A high-stakes piece | `objections`, `panel`, or `debate` |

The classic flow is available but optional:

```text
brainstorm -> interview -> outline -> draft -> dev-edit -> line-edit -> final-pass
```

Publication, project, and format standards come from the active `STYLE.md`, brief, template, or maintained workflow.

Use `save` to turn a confirmed preference or recurring lesson into maintained context.

Ask "Show me the Compound Writing toolbox" for the complete tool catalog and one-line descriptions.

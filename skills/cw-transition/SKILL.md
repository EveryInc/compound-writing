# Transition

## Purpose

Generate 3 transition options between sections, tailored to the piece type and content.

## Invocation

- `/cw-transition [context]` — Generate transitions for the specified sections
- `/cw-transition` — System asks "Which sections are you bridging?" then generates options

## Transition Patterns

| Pattern | What It Does | Use When |
|---------|--------------|----------|
| **Logical bridge** | Connects ideas through reasoning | Argumentative, logic-driven pieces |
| **Story flow** | Continues narrative momentum | Narrative or reflective pieces |
| **Sudden shift** | Deliberately jolts the reader | Tonal pivots, surprising turns |

## Anti-Patterns (Always Avoid)

Never use these transitions:
- "Furthermore"
- "Additionally"
- "Moreover"
- "Another point"
- "In addition"
- "It is also worth noting"
- "On another note"
- Any formal academic connector

## How to Generate

1. **Analyze the piece type** — Is it argumentative? Narrative? Reflective? Mixed?

2. **Understand the sections** — What's the ending idea of section A? What's the opening idea of section B?

3. **Select 3 approaches** weighted toward patterns that fit the piece type.

4. **Generate one transition per approach** — Each should be 1-2 sentences that bridge naturally.

5. **Present all three** with the pattern labeled.

## Output Format

```
## Transition Options

### Option 1: Logical Bridge
[1-2 sentence transition]

### Option 2: Story Flow
[1-2 sentence transition]

### Option 3: Sudden Shift
[1-2 sentence transition]

---

Which feels right for this moment? Or want me to try something else?
```

## Principles

- **Invisible is ideal** — The best transitions don't call attention to themselves
- **Each section should answer the previous question** — Create natural flow through implicit Q&A
- **Vary your moves** — Don't use the same transition pattern throughout
- **Earn the shift** — If you're making a sudden jump, the content should justify it

## Context-Aware Weighting

Adjust which patterns to emphasize based on piece type:

| Piece Type | Primary Pattern | Secondary | Use Sparingly |
|------------|-----------------|-----------|---------------|
| Argument/Analysis | Logical bridge | Story flow | Sudden shift |
| Personal essay | Story flow | Sudden shift | Logical bridge |
| How-to/Guide | Logical bridge | — | Sudden shift |
| Opinion/Take | Logical bridge | Sudden shift | Story flow |
| Profile/Narrative | Story flow | Sudden shift | Logical bridge |

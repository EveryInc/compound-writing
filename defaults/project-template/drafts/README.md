# Drafts

Create one folder per piece:

```text
drafts/
└── piece-slug/
    ├── notes.md
    ├── research.md
    ├── outline.md
    ├── draft-version-one.md
    └── review.md
```

Create only the files each piece needs. Keep its sources, notes, versions, and review passes together. Name iterations `version one`, `version two`, and so on rather than `final` or `clean`.

# Examples

This folder is where your voice comes from. Compound Writing reads these pieces before it drafts or edits and works out how your sentences sound from them: how they open and end, how long they run, which words you reach for, what punctuation you use, what you never do. There is no written description of your voice to keep up to date.

## What to put here

- Three to ten pieces you think sound most like you. Five is a good start.
- Pieces in the formats you write most. If you write essays and newsletters, include both.
- Your own sentences: drafts you wrote, or published pieces that were not heavily rewritten by an editor.
- Whole pieces or long passages. Short snippets do not show rhythm.
- Markdown or plain text (`.md` or `.txt`), one piece per file, with a name that says what it is.

## Optional counterexamples

Put pieces that sound wrong (an AI draft that missed, a version an editor flattened) in `examples/negative/`. They are used only to see what to avoid, never to learn the voice.

## Keeping the set honest

- Add a piece when you write something that sounds more like you than what is here.
- Remove a piece when it no longer sounds like you. The set should describe the writer you are now.
- When a draft keeps getting the same thing wrong, first ask whether an example would show it. If not, save the correction as a lesson in `VOICE.md`.

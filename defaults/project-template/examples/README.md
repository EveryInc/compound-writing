# Examples

Keep a small, curated set of writing examples that show the project's rules in action.

- Include positive examples worth learning from and negative examples that reveal recurring misses.
- Prefer full pieces or substantial passages with clear provenance.
- In `VOICE.md` or `STYLE.md`, name the exact rule each example demonstrates.
- Treat examples as evidence, not copy to imitate. Never reuse published language verbatim.
- Remove examples that no longer represent the project.

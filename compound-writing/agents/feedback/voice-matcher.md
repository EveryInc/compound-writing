# Voice Matcher

Load the user's `voice.md` and only the relevant destination style guide.
Identify aligned patterns, drift, and revision options. Distinguish a
destination convention from a cross-format voice preference.

Do not recommend durable updates unless the user requests learning; if a
possible pattern appears, flag it as a provisional observation.

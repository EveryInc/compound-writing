# Improvement Loop Tests

## Provisional Observation

When a user keeps a dry release line in one LinkedIn revision, the system may
ask to note the choice in `context.md`. It must not update a durable guide on
that evidence alone.

## Repeated Evidence

When the user repeatedly chooses the same LinkedIn humor constraint, the
system may propose an update to `style-guides/linkedin.md`, show supporting
observations, and wait for approval.

## Explicit Global Preference

When a user says, "Remember that I prefer dry understatement everywhere," the
system proposes precise wording for `voice.md` and writes it only after
confirmation.

## Pass Criteria

- The suggested destination matches the scope.
- Evidence and approval are visible.
- Durable files are unchanged before approval.

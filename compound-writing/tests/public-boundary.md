# Public Boundary Tests

## Public Core

Verify that bundled defaults and examples do not contain:

- A real user's personal writing profile, career strategy, or analytics.
- Private publication, Slack, or workspace-source material.
- Reviewer commands framed as imitations of named real people.
- An editorial-edition dependency required for basic use.

## Optional Edition

Verify that any separately distributed editorial edition:

- Explicitly depends on public core behavior rather than changing its
  workspace contract.
- Includes only cleared or deliberately generalized editorial guidance.
- Has its own distribution and documentation decision.

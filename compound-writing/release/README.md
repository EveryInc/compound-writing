# Release Checklist

Before treating this scaffold as an external release:

- Replace proposal status with approved product copy.
- Complete migration of retained generic skills from the current repository.
- Verify both `.claude-plugin/plugin.json` and `.codex-plugin/plugin.json`.
- Decide and include appropriate license, privacy, and terms materials.
- Confirm examples and defaults are public-safe.
- Test onboarding, legacy migration, destination routing, reviewer names, and
  the improvement loop.
- Confirm a new user can find `docs/GETTING-STARTED.md` and complete the
  preview-before-write onboarding flow.
- Decide whether an optional editorial edition is released, and under what
  access model.

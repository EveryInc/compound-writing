# Skill Inventory

This proposed repository includes skill contracts for the behaviors that
change under externalization.

## New Or Changed Contracts

| Area | Skills |
| --- | --- |
| Workspace and learning | `scribe`, `onboarding`, `migrate-workspace`, `save`, `voice-check` |
| Destinations | `longform`, `x-post`, `linkedin-post` |
| Public reviewer lenses | `trim`, `tension`, `momentum`, `humor`, `general-reader`, `stress-test`, `story-check` |
| Composition | `panel`, `debate` |

## Carry Forward After Migration

The live repository also contains useful generic capabilities such as
brainstorming, interviewing, outlining, developmental editing, line editing,
AI-pattern review, hooks, theses, promises, transitions, analogies, and
simplification. Those can be carried forward once their context-loading
language is updated to this workspace contract.

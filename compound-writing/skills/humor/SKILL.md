# Humor

## Modes

Look for absurdity, incongruity, deadpan observation, understatement,
self-implication, escalation, over-specificity, register collision,
callback, repetition, and short release lines.

## Destination Fit

| Destination | Default use |
| --- | --- |
| Longform | Earned aside, scene detail, or release line. |
| X | Compressed contrast, payoff, or artifact-supported observation. |
| LinkedIn | Brief professional recognition or self-aware release. |

Load `voice.md` and the destination style guide before proposing revisions.
Offer humor opportunities; do not insert a comic persona the user has not
chosen.

If repeated user decisions reveal a stable humor preference, propose the
appropriate durable file update through `save`.

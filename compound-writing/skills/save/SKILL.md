# Save

## Purpose

Make improvement over time visible and scoped correctly.

## Routing

| Learning | Destination |
| --- | --- |
| Cross-format voice, syntax, diction, or humor preference | `voice.md` |
| Destination-specific behavior | `style-guides/{destination}.md` |
| Public territory or reader promise | `strategy/professional-positioning.md` |
| Platform job, reuse rule, or measurement decision | `strategy/platform-strategy.md` |
| Single instance or unconfirmed pattern | `context.md` |

## Approval Rule

If the user explicitly says to remember or save a durable preference, propose
the destination and write only after they agree to the wording and scope.

If the system merely notices a pattern, record it only as a proposed
observation after permission, or ask whether the user wants it recorded.

Never save draft phrasing, anecdotes, personal facts, or performance results
as reusable guidance without explicit approval.

# Commands

## Start And Learn

| Command | Purpose |
| --- | --- |
| `/scribe` | Route the current request into the right writing workflow and destination. |
| `/onboarding` | Guided first-run setup: preview and create a sparse `voice.md`, then optional destination or strategy files. |
| `/migrate-workspace` | Propose a reviewed split of a legacy `TASTE.md`. |
| `/save` | Route an approved preference or a provisional observation. |
| `/voice-check` | Review passage alignment with `voice.md` and destination guide. |

## Destinations

| Command | Purpose |
| --- | --- |
| `/longform` | Draft or review essay, newsletter, or article work. |
| `/x-post` | Draft or review an X post or thread natively. |
| `/linkedin-post` | Draft or review a LinkedIn post natively. |

## Review Lenses

| Command | Purpose |
| --- | --- |
| `/cut` | Remove bloat while preserving the writer's meaning and voice. |
| `/tension` | Surface stakes, uncertainty, and reveal timing. |
| `/momentum` | Restore forward motion where a draft stalls. |
| `/humor` | Find suitable comic possibilities for the destination. |
| `/general-reader` | Surface jargon and missing context. |
| `/stress-test` | Challenge claims, logic, assumptions, and proof. |
| `/story-check` | Check entry point, want, consequence, change, and payoff. |

## Multi-Reviewer

| Command | Purpose |
| --- | --- |
| `/panel` | Run multiple functional lenses and synthesize their findings. |
| `/debate` | Have lenses resolve genuine editorial tensions. |

# Platform Strategy

Status: User-owned strategic guide.

This file assigns each publishing destination a job and defines how real work
can generate multiple platform-native expressions without becoming a content
churn machine.

## Core Work Unit

One real episode can produce:

1. A problem, friction, question, or observation from actual work.
2. An experiment, decision, or attempt.
3. A visible receipt, such as an artifact, screenshot, comparison, result, or
   useful excerpt.
4. A conclusion the intended reader can use.
5. Destination-native treatments rather than copied text.

# X Style Guide

Status: Fictional example.

## Platform Job

- Make experiments inspectable for researchers and civic technology
  practitioners.
- Prefer a screenshot, annotated comparison, or public document link over an
  abstract opinion about AI adoption.

## Post Shape

- Open with the document or test performed.
- Name one result or failure.
- End with the artifact or the accountability lesson.
- Use threads only when the procedure itself is worth reproducing.

## Humor

- A dry observation about administrative friction can release tension.
- Do not make a joke out of errors that would affect public decisions.

# Example Workspace: Independent Researcher

Everything in this folder is fictional. It lets reviewers see how the blank
templates could become useful after onboarding, without distributing a real
person's voice profile, analytics, relationships, or publication history.

## Scenario

Alex Rivera is an independent researcher who studies how small city agencies
adopt AI tools. Alex publishes field notes, runs small workflow experiments,
and wants to be useful to public-sector operators without turning every post
into either hype or policy abstraction.

## The Source Episode

Alex tested a tool-assisted process for converting a public hearing
transcript into a claim-checked briefing. The files show how one piece of work
can be held in memory and then shaped for different destinations:

- Longform can explain the workflow and its failure points.
- X can show the annotated artifact and one surprising correction.
- LinkedIn can address the professional question: what should an operator
  delegate while remaining accountable for the briefing?

## Take A Tour

Read the files in this order:

1. `strategy/professional-positioning.md`
2. `strategy/platform-strategy.md`
3. `voice.md`
4. `context.md`
5. `style-guides/longform.md`
6. `style-guides/x.md`
7. `style-guides/linkedin.md`

As you read, look for the separation the product is trying to enforce:

- `voice.md` travels across destinations.
- Each style guide changes the treatment for its own surface.
- Strategy clarifies public purpose without becoming voice.
- `context.md` can hold current observations before they become durable rules.

# Example Workspace: Independent Researcher

Everything in this folder is fictional. It demonstrates how an external user
might populate the strategic layer of Compound Writing without providing a
real person's personal profile, analytics, or publication history.

## Scenario

Alex Rivera is an independent researcher who studies how small city agencies
adopt AI tools. Alex publishes field notes, runs small workflow experiments,
and wants to be useful to public-sector operators without turning every post
into either hype or policy abstraction.

## Demonstrated Pattern

One work episode:

- Alex tested a tool-assisted process for converting a public hearing
  transcript into a claim-checked briefing.
- Longform can explain the workflow and its failure points.
- X can show the annotated artifact and one surprising correction.
- LinkedIn can address the professional question: what should an operator
  delegate while remaining accountable for the briefing?
